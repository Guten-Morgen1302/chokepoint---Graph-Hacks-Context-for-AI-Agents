## Edge Cases

- **The agent's plan does not sever.**
  - Value: protects=verify gates every chosen plan; fails_when=verify skipped or cf misread as 0; why_new=no severance proof existed in v1; seam=none
- **A constraint has no Doc, Ticket or Message cite.** It is rejected, and the trail shows ✗.
  - Value: protects=citation guard; fails_when=grant ids alone accepted as evidence; why_new=guard is new; seam=none
- **Two tabs run counterfactuals at the same time.** The numbers are correct in both.
  - Value: protects=per-graph cf lock; fails_when=cf written outside lock; why_new=cf is new; seam=none
- **A crash leaves `cf` behind.** The next request succeeds.
  - Value: protects=clear-before-check order; fails_when=verify_caps runs before clear; why_new=cf is new; seam=none
- **Every route is forced through grants that must be kept.** The result is NoRevocableCut, and the agent escalates with a recommendation to accept the risk plus a rotate-token control.
  - Value: protects=infeasible keep handling; fails_when=BIG maxFlow rendered as a plan; why_new=what_if is new; seam=none
- **The agent times out, refuses, or the demo is in read-only template mode.** P0 is shown, labelled "Not reviewed by agent", and severance comes from the min-cut theorem.
  - Value: protects=deterministic floor; fails_when=card blank or unverified; why_new=agent hero is new; seam=none
- **A prompt-injection message is in the fixtures.** The chosen plan doesn't change, and no decision is written.
  - Value: protects=untrusted-text handling + proposed-only ACCEPT_RISK; fails_when=agent obeys text or commits a decision; why_new=knowledge text is new; seam=none
- **A decision's `review_by` date has passed** (with an injected clock). The badge shows NEEDS REVIEW · review_overdue.
  - Value: protects=negotiation lifecycle; fails_when=expired acceptance silently HOLDS; why_new=review_by is new; seam=none
- **A cited source node is deleted.** The badge shows STALE · source_removed, and `cited_ids` still names the deleted source.
  - Value: protects=provenance integrity; fails_when=CITES edge loss hides the cause; why_new=cites are new; seam=none
- **Extraction adds an extra GOVERNS edge.** CI fails.
  - Value: protects=policy_status correctness; fails_when=extras only warn; why_new=ingest is new; seam=none

## Pre-freeze additions (Part D)

- **SD-1, Menger:** `routes` is computed with a single unit-capacity maxFlow into the virtual super-sink, and it must equal networkx's result with an explicit `__SINK__` node. The assertion is `routes ≤ |P0|` and must never be `==`. The `menger-strict` fixture has routes < |P0|. A shared-grant test proves that summing per-jewel flows is wrong.
  - Value: protects=route metric and demo copy math; fails_when=per-jewel sum, == assertion, or routes compared to cost; why_new=only random-graph checks existed; seam=none
- **SD-2, `with_capacities`:** `cf` must be flushed after maxFlow raises and after cancellation (`asyncio.shield`). A failed cleanup sets `cf_dirty`, and the next call either heals it or raises `GraphUnavailable`. Garbage `cf` on random edges must not change the result (overwrite-before-read). `unit` and `cap` must never be touched.
  - Value: protects=no poisoned residual; fails_when=cleanup skipped on cancel or stale cf read; why_new=only the raise path was tested; seam=none
- **SD-3, distractors:** 3 distractor docs (DX-1…3) mention `deployer` with dependency-sounding verbs but don't block revocation. A CI test, `test_keyword_baseline_is_wrong`, confirms that keyword matching picks the wrong plan. The eval gate requires 3 out of 3 real-model runs to keep only the DR grant and cite only runbook §3.
  - Value: protects=the agent-reasoning claim; fails_when=fixture edit makes regex accidentally right, or model cites a distractor; why_new=no distractors existed; seam=none
